# Changelog

## 0.1.1

- Install the Linux Qt EGL runtime library in the release runner.
- Make font tests use available fonts on Linux and Windows.

## 0.1.0

- First public release of Painter for Linux and Windows.
- RGBA painting, layers, gradients, editable object history, and grid snapping.
- Reusable custom objects with edit and delete controls.
- Single-file portable builds and automated release workflow.
